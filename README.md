# Bike Sharing Demand Explorer

An interactive Streamlit app for exploring hourly bike rentals in Washington, D.C. from 2011–2012.

The **Overview** page shows rental summary metrics and charts for demand by hour, day type, season, month, weather, and rider type. Sidebar filters let you select years, seasons, day types, and weather conditions; you can also choose to view a preview of the raw data. The **Conclusion** page summarizes the main patterns and limitations.
